One line summing up a week of entering 100+ make.fun coding bounties: a token-radar
entry clinging to the top-40 shortlist by 0.14 points, and nothing else to show for it.

Running `main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), exactly one line, no trailing newline.
